# Inventory Management System
A Python-based inventory management system developed to manage products, prices, quantities, and inventory value
The project started with file-based storage and was later upgraded to SQLite database storage.
## Features
- Add products
- View products
- Search products
- Update product information
- Delete products
- Calculate total inventory value
- Store inventory data in text file
- Store inventory data in an SQLite database
- Handle invalid user input and error
## Technonologies used 
- Python
- SQLite
- SQL
- Git
- GitHub
- VS Code
## Project Development
### Version 1 - File-Based Inventory System
The First version of Project used Python Data structure and a text file to store inventory system information.
It included Function adding, viewing, searching, updating, and deleting products.
### Version 2 - SQLite Inventory System
The second version upgraded the project to use an SQLite database.
The database stores the product information including:
- Product ID
- Product name
- Price
- Quantity
- Total value
The SQLite version also included database operations for adding, viewing, searching, updating, and deleting products.
